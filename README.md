# Jonathan Yu — Application Portfolio

Personal resume / portfolio one-pager for **Jonathan Yu**, a builder-educator behind [Sip Studies](https://sipstudies.com) and [Sipopedia](https://sipopedia.com).

This is a Vite + React + TypeScript single-page site. The production build is static (`dist/`) and can be hosted on GitHub Pages, Netlify, Vercel, or any static host.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints, typically [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Build

```bash
npm run build
npm run preview
```

`npm run build` typechecks and writes a static site to `dist/`. `npm run preview` serves that folder locally.

## What’s on the page

1. **Hero** — builder-educator positioning, credentials, and CTAs to contact / LinkedIn.
2. **Case studies** — three featured products with sites-within-a-site previews:
   - [Sipopedia.com](https://sipopedia.com) — live embed plus Learn / Taste / Connect product map
   - [Coffee Index](https://github.com/Sip-Coder/Coffee-Index) — interactive tasting / market-index preview
   - [Zen Noise](https://github.com/Sip-Coder/Zen-Noise) — ambient mixer preview ([Replit](https://replit.com/@SipStudies/Zen-Noise))
3. **Selected work** — smaller cards for Biz-Bookkeeper, Rose Quartz, sunset-in-monaco-rpg, and the earlier application demo (layout reference only).
4. **Contact** — email, LinkedIn, GitHub, and Sip Studies channels.

Public project copy is drawn from live Sipopedia / Sip Studies pages and public Sip-Coder repositories. Those other repos are not modified from this site.
